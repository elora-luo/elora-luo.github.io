# 上传步骤（5分钟，不需要写代码）

1. 注册 GitHub，新建仓库，名字必须是：你的用户名.github.io（公开/Public，勾选 Add a README）
2. 打开这个仓库 → 点 "Add file" → "Upload files" → 把本压缩包解压后的
   所有文件和文件夹拖进去（保持 _posts 文件夹结构）→ 点 "Commit changes"
3. 仓库 Settings → 左侧 Pages → Source 选 "Deploy from a branch"，
   分支选 main / (root) → Save
4. 等 2-5 分钟，访问 https://你的用户名.github.io

发新文章：仓库里进 _posts 文件夹 → Add file → Create new file →
文件名格式必须是：年-月-日-英文标题.md，开头照抄已有文章的格式。
